# 🌟 Wardrobe - Digital Fashion Manager

一個精美的衣櫃管理應用，幫助你追蹤衣物、記錄每日穿搭和分析購物數據。

## 📱 功能特點

- **OOTD Journal** - 記錄每日穿搭
- **衣物管理** - 添加衣物並追蹤穿著次數
- **成本分析** - 計算單件成本和單次穿著費用
- **多幣種支持** - 支持 6 種貨幣實時匯率
- **個人檔案** - 查看衣櫃統計數據

## 🚀 快速部署到 Vercel

### 方式 1：一鍵部署（最簡單）

1. 點擊下方按鈕一鍵部署：https://vercel.com/new

2. 選擇「Import Git Repository」

3. 貼上你的 GitHub 倉庫 URL

4. 點擊「Deploy」
